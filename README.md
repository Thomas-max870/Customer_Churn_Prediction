# Customer Churn Prediction

## Project Overview
This project predicts customer churn using Machine Learning.

## Dataset
Telco Customer Churn Dataset

## Technologies Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-Learn

## Exploratory Data Analysis
- Gender vs Churn
- Contract Type vs Churn
- Monthly Charges vs Churn
- Tenure vs Churn

## Model
Logistic Regression

## Accuracy
82.39%

## Results
The model successfully predicts customer churn with good accuracy.
